# Watch Money 前端

React 18 + TypeScript + Vite 的中文本地市场观察台。公开行情、成本、时间戳、资产身份与数据来源均使用后端接口；没有内置静默填充的模拟行情。

## 启动

需要 Node.js 20.19+ 或 22.12+、npm，以及运行在 `127.0.0.1:8000` 的项目后端。

```bash
cd frontend
npm ci
npm run dev
```

打开 Vite 输出的本地地址（默认 `http://localhost:5173`）。开发服务器把 `/api` 与 `/ws` 代理到后端 8000 端口。

生产构建：

```bash
npm run build
```

构建同时执行严格 TypeScript 检查，生成 `frontend/dist`，项目后端从同一来源提供页面。独立类型检查：`npm run typecheck`。

## 已实现交互

- 总览按内部 `asset_id` 聚合，支持平台、链、产品、搜索、名称/市场数/接收时间排序、展开市场和持久化收藏。价格范围按报价币独立展示，不把 USD、USDT、USDC 或法币默认等价。
- 资产详情并列展示现货/池子和永续/RFQ，包含原始资金费率、实际周期、8 小时归一化、费率含义、下次结算倒计时、字段时间、历史 SVG 图、按需订单簿、池合约及来源元数据。协议借贷费和状态指标独立保留原始字段名、数值与单位，不转换成资金费率。
- 平台页分别展示真实连接诊断与覆盖登记，包含数据源传输方式、源 WebSocket 状态/重连次数、采集重试、限流、解析错误、缺失能力、接入条件、受限及暂不支持状态；源链路与页面推送连接分别标明。
- 配置页支持模块与平台开关、优先行情 WebSocket（含 REST 回退）、关注资产、采集周期、页面合并刷新、过期阈值、保留期、RPC、显式演示模式、人工资产映射与审计记录。
- 计算器支持七类策略、任意报价币金额或基础数量、批量基础数量、持有期、开平仓与持仓费、额外成本、带来源及时间的跨币种汇率、资金费名义价值假设、显式退出价假设、按需深度、场景结果、成交容量与成本明细、保存和延迟回放。
- 计算结果可创建持续监控，展示最后结果并支持暂停、继续和删除。监控保留计算时的基础资产数量，后端更新行情并触发通知规则。
- 通知页支持规则创建、编辑、删除、资产/平台/策略/事件范围、金额/收益/费差/回本/容量阈值、持续与连续命中、冷却、优先级、UTC 时段、独立渠道选择、测试消息、本地中心及发送重试记录。

## 数据与运行行为

- 初始显示空数据；接口错误可见并可重试。WebSocket 断开后 5 秒尝试重连，并以 15 秒 REST 轮询保持降级更新。
- WebSocket 市场更新按配置的 `refresh_ms` 合并应用。页面刷新频率不被当作行情源更新频率；按实际展示价格使用的字段（买卖中间价、最新价、标记价或指数价）独立计算年龄，取相应字段来源与本地接收时间中的较早值；只更新最新价不会刷新旧盘口中间价的年龄。各字段时间独立显示。
- 数值缺失显示“未提供”，费用空白表示待配置，显式输入 0 表示使用零成本假设。资金费字段无专属时间戳时显示“字段时间未提供”。
- 演示数据仅由后端显式开启且带标签；演示设置会显示全局提示，具体快照保留 `is_demo` 标记。页面不生成自有假数据。
- 非订单簿市场需要真实的指定规模路线报价；前端不把池展示价格冒充可执行价格。当前界面不配置外部路线报价服务或私有凭证；后端缺少路线深度时显示明确前置条件。
- 私有渠道凭证、代理和可选平台 API key 配置在后端环境；前端不读取或回显凭证。外部渠道未配置时显示状态，实际渠道可用性以真实发送记录为准。
- 同名币不会通过 ticker 自动合并。人工映射操作需要操作者先核对链、地址与包装关系；后端保留审计。
