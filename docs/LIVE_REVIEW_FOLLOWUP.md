# 外部实测反馈与后续修复

父线程提供的独立实测基于62f1815：约150秒得到6900个真实快照。可靠盘口：OKX 1748/1750、Bitget 4586/4597、Hyperliquid 3/347、Lighter 0/213。OKX资金费有效数曾540→6→恢复；部分源时间到达时接近60秒。此处是父线程报告，不是当前环境新采集或24小时证据。

本轮关注：

- Hyperliquid/Lighter：全目录REST统计并不包含可核验双边盘口。既有源流仅关注watch_assets，导致全目录计数增长而有效盘口不足。仅对已审查支持的平台启用全目录源流；订阅预算、选取/请求市场数和截断在诊断中显示。订阅数不等于有效快照数，数据仍受逐字段来源时间校验。
- OKX：网络接收时间不能替代源时间；缩短实际重查间隔可减少抓取造成的空档，但不能消除源端本身陈旧造成的无效区间。具体调度和限制见COLLECTION.md。
- 资产身份：每个平台必须有本地币种ID→链/合约的可追溯证据。不能把同ticker或产品名称一致当跨平台身份证据。批量源及冲突统计见ASSET_VERIFICATION.md；主网实际新增可靠组数须外部再次实测。

本轮实现、官方依据和最终测试数由审计清单及各模块说明记录。当前环境尚未完成成功实网验收，不将模拟数据写入上述真实计数。

当前环境补测KuCoin `/api/v3/currencies`、Coinbase Exchange `/currencies`、Lighter `orderBookDetails` 均为ProxyError，使用既有代理及默认TLS，未绕过策略；记录见 [live-review-public-probes.json](evidence/live-review-public-probes.json)。因此当前提交只能交付官方契约实现及合成回归，真实新增身份组数和源流覆盖率需等待外部复测。

外部复测应分别记录：活跃目录数、来源scope可核对数、证据导入/冲突/待审核数、应用后的可靠跨平台组数；HL/Lighter记录源流选取/预算截断与逐字段有效盘口数量；OKX持续记录接收到的源年龄P90/最大值、实际轮转和过期/缺失源时间数量。不要只以快照总数判断完成。
