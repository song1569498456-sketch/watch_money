# 监控界面与使用流程

主导航为 **市场监控、我的监控、通知记录、设置**。首次打开进入价差；市场监控内可切换价差、资金费、全部市场。

1. 在价差资产表搜索、筛平台及市场类型，核对覆盖与更新时间。盘口价差尚未扣成本，不是可实现利润。展开后检查两腿交易对、双向报价与各自时间；查看资产详情或点击“测算此组合”。
2. 测算页带入精确两腿，基本区填写规模、持有时间及费用，查看缺失项。退出情景、汇率和批量规模等位于高级假设。未知费用保持未知；计算后可保存样本或创建持续监控。
3. “我的监控”独立展示已创建的持续监控，可查看状态、暂停或删除。关注市场与持续监控组合是不同操作；资产列表关注按钮说明实际关注的代表市场，展开后可逐市场关注。
4. 返回发现页面保留本次页面会话的搜索、筛选、排序、展开与滚动位置。网页重新加载后不承诺恢复这些临时条件；已保存关注、配置与监控由后端持久化。

资金费默认跨平台矩阵，并可切换单平台排行。矩阵保留原始周期，8 小时归一化只用于比较，不代表实际结算收益。详情提供费率类型、结算时间、字段来源时间及已有历史入口。无市场只表示当前已发现目录内没有市场，不证明平台从未上线该资产；未知身份、未采集、过期与周期缺失分别标记。

身份映射、原生池诊断和数据源覆盖入口放在设置。通知记录保留发送结果和规则管理。全部功能仅用于监控和辅助分析，不导入账户，不提供下单入口。

扫描预算、返回上限、未知身份和实时覆盖不足仍会显示；界面调整不扩大后端实网验收结论。剩余计划见 [AUDIT_BACKLOG.md](AUDIT_BACKLOG.md)。
