# Shared integration contracts

Python package `backend/watch_money`, import `watch_money`. Shared Pydantic models in `models.py` owned by main integrator. All timestamps UTC epoch milliseconds, all rates fractions (0.0001 = 0.01%), no missing numeric values replaced with 0. Source identity and demo flags must survive storage and UI. Unknown assets remain venue scoped until explicit verified mapping. Preserve quote currencies.

Adapters: async `discover() -> list[Instrument]`, `fetch(instruments: list[Instrument]) -> list[MarketSnapshot]`, `orderbook(instrument: Instrument) -> OrderBook`, `close()`. Each adapter has `venue`. `adapters/cex.py`: `build_cex_adapters() -> dict[str, adapter]`; `adapters/dex.py`: `build_dex_adapters() -> dict[str, adapter]`. Each module exports `coverage() -> list[CoverageEntry]`. Dependencies can be imported lazily; do not contact network at import. Adapter constructors default no account credentials. Return no fabricated snapshots on error. Raise failures for collector state/backoff.

API (integrator): GET /api/health; GET /api/markets -> {instruments: Instrument[], snapshots: enriched MarketSnapshot[]}; GET /api/status -> {venues: VenueStatus[], coverage: CoverageEntry[]}; GET/PUT /api/settings -> Settings; GET /api/assets; PUT /api/assets/mappings; GET /api/history?instrument_id=...&limit=500 -> {snapshots: []}; GET /api/orderbook/{instrument_id:path}; WS /ws -> type=markets + same payload as /api/markets. GET/PUT /api/favorites -> {instrument_ids: string[]}. Snapshot enrichment: age_seconds, stale, funding_8h, mid. Serve source metadata and clearly label demo; default demo off. Strategy and notification modules export APIRouter named router, endpoint prefix owned by modules. Main `app.py` calls `app.include_router(router)` for both.

Strategies: module `strategies.py`, exported router prefix `/api/opportunities`; calculator request accepts explicit instruments/snapshots/orderbooks, not implicit global state. Implement endpoint `/calculate`, `/saved` GET/POST, `/replay`; strategy persistence can use own sqlite file from WATCH_MONEY_DATA_DIR (default data). Notification module `notifications.py`, router prefix `/api/notifications`, factory `NotificationService(data_dir)` with async `start()`, `stop()`, `evaluate(event: dict)`. Service uses own sqlite, router accesses `request.app.state.notifications`. Routes rules GET/POST/DELETE, history GET, test POST. No real send without explicit configured credential and channel selection. Local center is default.

Main owns pyproject, app.py, collector.py, storage.py, models.py, startup/CI scripts, top-level docs. CEX agent owns cex.py and tests/test_cex.py, docs/CEX_SOURCES.md. DEX agent owns dex.py and tests/test_dex.py, docs/DEX_SOURCES.md and deployments.json. Frontend agent owns frontend/**. Strategy agent owns strategies.py and tests/test_strategies.py, docs/CALCULATIONS.md. Notification agent owns notifications.py and tests/test_notifications.py, docs/NOTIFICATIONS.md. QA agent initially read-only audit + own tests/test_acceptance.py and docs/ACCEPTANCE.md. Do not commit or touch others' files; main integrates commits.

Follow-up contracts: `Instrument.native_asset_id` preserves catalog identity through manual mappings. Asset review and calculator identity gates are shared. `GET /api/scanner` enumerates indicative cross-venue candidates; `GET /api/funding` provides full-catalog rate rows/groups. They do not invent executable net returns. Historical settlement records use a separate `GET /api/funding/history/{instrument_id:path}` service, not `/api/history` sampled snapshots. Catalog/public period metadata may carry a null event timestamp and a tagged explicit observation timestamp, with a six-hour maximum age; current rate/next settlement and other market fields retain their separate freshness rules.
